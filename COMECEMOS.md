## 🔧 Usar nos Seus Formulários

### Para o formulário de inscrição:
```javascript
// Depois de salvar em localStorage:
await enviarEmailNovaInscricao({
  nome: 'João',
  email: 'joao@exemplo.com',
  curso: 'Informática'
});
```

### Para o formulário de contacto:
```javascript
// Depois de submeter:
await enviarEmailContacto({

  assunto: 'Dúvidas',

});
```
